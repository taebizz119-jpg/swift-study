}

- "\(값)" -> String 안에 (값)을 출력
- \n -> enter
- \t -> tab
- 코드를 짜기 전, 먼저 매끄러운 문장을 만들 것. 코드를 읽을 때도 매끄럽게 읽혀야 함.
